## 2026-10-06 当前阶段部署D补偿数值勘误

当前待验收训练阶段的轮端反馈`D_fb=.05`在电磁clip内，机械被动黏性先验`b=.002`在clip外；未饱和时总系数`.052 Nm·s/rad`。若部署端把实机被动b暂按0处理，显式左右轮`D_comp=.052`，而不是仅写`.05`。若后续实测`b_real`，则目标`D_comp=.052-b_real`，仍需与当前checkpoint阶段契约核对。C参考值为`RMUC_STAGE_D_COMP_NM_S_RAD`，调用者必须显式填充左右轮校准槽位；它不是已验证的实机默认值。

## 2026-10-06 当前候选：主动部署D，覆盖旧后置反馈D目标

用户选择以部署低层反馈补足阻尼，不继续向纯机械b下探。机械b仍[.001,.005]先验；目标是未饱和时总有效D[.04,.06]。拟部署D_fb=.048，b=.002时总D=.050；训练目标D_fb[.039,.055]与b[.001,.005]独立采样，属于工程范围，未验收。低层反馈在轮输出轴1ms执行，必须纳入训练，保持腿PD2ms/policy8ms。硬件轮速符号、rad/s单位、counts/Nm和实际电磁限幅必须验证；无需精确辨识b不等于跳过接口验证。

```text
tau_policy = 5.5 * wheel_action_sign * clip(action, -1, 1)
tau_em = clip(tau_policy - D_fb * omega, -5.5, 5.5)
tau_net = tau_em - b * omega - C * tanh(omega / omega_eps)
```

此为`active_motor_v1`，电机只有±5.5电磁限幅，净轴力矩无外层clip；3Nm仍仅持续热参考。主动反馈使用电机能力，不能放在电磁clip后冒充无限被动力；被动b/C始终在限幅后。D总和仅是未饱和、无额外滞后的局部等效，饱和占比与延迟必须随策略验收。C核心报告policy/feedback/electromagnetic分量，实际写电流只用electromagnetic总量；不能再次将被动b/C写入电流。

## 导出actor不是完整的实机controller

当前仿真链是：完整组合actor → action限幅及速度/pitch/yaw外环反馈 → 动作通信延迟 → 轮端力矩换算/限幅 → 显式执行器。25D中的历史动作也有既定执行语义。

用户进一步明确最终必须E2E RL：这些速度/pitch/yaw/推进外环只可作为过渡teacher，必须通过训练吸收并移除，最终不允许复现它们来替代策略能力。不能仅缩放ONNX输出而遗漏旧checkpoint所依赖的执行语义，也不能同时叠加LQR而改变学到的闭环。

最终允许状态估计、单位换算、执行器底层控制、限幅和急停；不允许actor后增加任务级速度/pitch/yaw反馈。当前外环含真值来源，旧结果仅过渡基线。新增policy_outer_feedback_enabled开关用于明确剥离，默认True只为历史复现，不代表最终契约；最终验收必须False。

## 物理与辨识

优先辨识有效输出力矩增益、死区、反转迟滞、响应时间及限幅；不要求先精确分解每个齿轮的摩擦和柔度。依据实测不确定区间做DR，不用任意大范围掩盖错误模型。

旧显式D0.1形成的−D*omega制动力不必然是实机机械损耗。此前依据4m/s得到的有效黏性上界也是条件估计，不是已标定电机参数，更不是速度环Kp。重心/接触、摩擦与传动损耗仍需分别核对。

## 轮端damping与速度语义（当前实现，2026-10-01核查）

轮端是直接输出力矩，Kp=0，没有目标轮速闭环。电磁限幅和轮端阻尼/摩擦分开执行：

```text
tau_cmd = clip(5.5 * clip(action, -1, 1), -5.5, 5.5)
tau_wheel = tau_cmd - D_fb * omega - b * omega - tau_c * tanh(omega / omega_eps)
```

唯一电磁限幅是`tau_cmd`的±5.5Nm；3Nm只作持续热/负载参考。反馈D、机械被动黏性和库仑摩擦均在限幅后作为内部轮轴力矩施加，合力矩不再外层clip，并对轮与父连杆施加等反作用力。Isaac wheel actuator自身damping必须为0，避免它在IdealPD内部先混入电磁力矩再被峰值clip；MuJoCo对同一力矩分解执行，且清除轮关节MJCF原生被动damping以免重复计算。

机械被动黏性先验`b=0.002 Nm·s/rad`（工程范围[0.001,0.005]），库仑先验`tau_c=0.001 Nm`，均未实测。`D_fb`绝对值仍未知；零值仅是无反馈基线，任何非零值都是显式诊断假设。不能把它称为固件速度环增益：给出的M3508 speed PID参数为0，旧LQR/近零速补偿不属于最终E2E actor。`omega_eps=0.1 rad/s`仅为平滑诊断参数。

- 通用历史配置D=.1，当前locomotion课程名义D=.080625。v393低强度DR范围[.07659375,.08465625]，它是旧工作点附近的初始课程，**未覆盖目标范围**。
- 目标工程先验D范围[.005,.04]，中心.0225，尚未实测标定、尚未鲁棒验收。恢复新默认D=.0225；旧checkpoint必须恢复自己存档的D，不得偷换。跨引擎运行必须显式使用相同阶段D/DR。
- 配置中的`velocity_limit_rad_s=63.3734`为输出轴轮速参数，约605rpm；半径.06m下纯滚动对应约3.802m/s。它不是任务速度指令范围，也不能当作已验证的无载转速。
- 当前使用IdealPDActuator，不是DCMotor；其输出只按effort limit裁剪，未实现随转速衰减的电压/反电动势包络。轮`velocity_limit_sim`未显式配置，当前原生日志的solver轮速上限约1.7e4rad/s，**并非63.3734rad/s硬封顶**。不能据配置有此数就声称速度能力已建模。
- 真实RM3508+C620转速—力矩/电压关系仍待核对；以后引入速度包络或显式solver速度限幅，必须同步Isaac、MuJoCo和部署契约并复验，不能只在部署端加clip。当前不热改正在训练/评估的模型。
