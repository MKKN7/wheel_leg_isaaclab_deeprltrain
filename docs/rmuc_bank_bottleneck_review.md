# 低速压弯瓶颈复盘（2026-09-26，v217）

当前优先级由用户明确为先克服压弯，不推进速度环迁移或部署扩展。本轮不增加critic输入、不启动长训练，先区分奖励信号与动作可达性。

## 已确认因果链

1. 原bank目标符号错误，旧策略被引向外倾；v212修正评价后，1m/s±0.8/±1全部bank失败。v208的100次更新发生在旧bank目标下，不能作为“修正后仍然学不会”的训练证据。
2. 修正符号没有自动生成有效远距离学习信号。生产惩罚abs(error)/6在1封顶，正奖励是1.5°容差的Gaussian。旧策略约9–12°误差落在惩罚平台和Gaussian尾部。v217执行真实_get_rewards AST并使用v208运行标量：12→11.9°的bank项差在float32为0；总体微小增益主要来自趋近直立项。这是奖励地形证据，不是PPO反传梯度或完整动力因果证明。
3. v208只训练一个正向1rad局部分支，不能修复全部双向低速外倾；冻结旧actor不等于冻结新任务所需姿态。其腿std0.004且freeze_action_std，原腿动作部分超过clip=1，新分支小残差可能先被执行限幅吞掉。v208固定状态新域输出最大变化仅0.001211。需测执行后的关节目标变化，不能以“参数更新过”替代有效动作变化。
4. v213常数腿差动0.24可减少外倾，但没有获得完整内倾。未证明机器人物理上做不到，更没证明增加侧滑罚就能解决。
5. 1m/s额外fine-yaw项仍未启用，bank scale实际1而非2；这些是后续低速转弯资格问题，本轮保持以隔离bank改动。真实heading侧向速度此前只有约0.01m/s，旧滑移指标含正常内外轮差速，不能据此大幅增加滑移惩罚。
