# RMUC 地胶课程：接触对先验与验收

2026-10-13 用户授权：参考3mm荔枝纹PVC地胶+胶合板，但不要求照抄所给数值，以实际地胶鲁棒性为目标。当前材料数值为工程先验，非实测标定、非已认证赛场标准。

## 参数口径

配置：`configs/rmuc_arena_ground.json`。定义的是轮胎—地胶接触对有效值：新地胶static/dynamic=.65/.55，磨损/碎屑下限先验=.45/.38；restitution目标.02。静/动摩擦按同一个severity插值，避免无关独立抽样制造错误组合。下限不是实测最差保证，有日志/实测后修订。

当前Isaac机器人接触形状摩擦约.5（实际DR=.1时约.49–.51），地面.5。直接把地面改.65/.55且使用multiply，若该规则生效将得到.325/.275。因而新契约采用显式轮胎材质摩擦1×地面目标值的参数分解；轮胎restitution=0、地面=.02，restitution combine=max。这仅是接触对参数化，不是说真实橡胶摩擦为1。只绑定轮胎接触材质，保留其他刚体材质；两侧combine模式及真实接触参数必须读回，不能只查配置对象。

**Isaac runtime尚未接入此profile，也没有切换当前课程。** 接入时禁止同时叠加现有全局friction倍率和独立地胶severity，除非实验契约显式声明最终联合范围。当前训练/自动验收地面保持原值，保存可比基线。材料测试先与D、弹簧、奖励和命令扩域分开。

## MuJoCo候选

生成器：`scripts/rmuc_arena_ground.py`，显式输入基线`rmuc_peak55.xml`，禁止覆盖已存在输出。

- `artifacts/arena_ground_20261013/rmuc_peak55_pvc_fresh.xml`
- `artifacts/arena_ground_20261013/rmuc_peak55_pvc_worn.xml`
- 对应manifest保存源/产物SHA，`static_validation.json`保存编译和实际接触构造读回。

通过显式wheel-ground pair使滑动摩擦分别为.55/.38，避免默认轮几何.5与地面组合时把磨损档抬高。MuJoCo常规接触不独立表达这里的静/动两档，因此并不与PhysX摩擦模型严格等价。

`friction`三元组不是静摩擦/动摩擦/弹性；当前condim3保留，扭转/滚动分量不参与。禁止为“加阻尼”随意改condim6或滚动摩擦，否则会与电机D及机械b/C混淆。plane size是平面显示尺度等属性，不等于3mm弹性层；3mm先作为真实地面结构元数据，不增加未经验证的柔性动力。

保留基线solref=.008,1与solimp=.9,.99,.002。用户参考solimp=.005,.02,.5不能解释成3mm厚度或恢复系数；这会显著改变约束阻抗，故不直接应用。MuJoCo没有一个可直接替代PhysX restitution=.02的相同标量，须由接触/冲击响应另行验证。

CPU核对已通过：两候选质量/惯量/惯性坐标、关节轴/范围、几何位姿尺寸、执行器gear/ctrl/force范围、闭链eq_data/solref/solimp与基线一致；实际组装出的轮地contact滑动摩擦为目标值。未运行策略闭环，未认证地胶sim2sim。官方文档联网检索本次失败，以上具体候选以本机MuJoCo3.8.0编译与接触读回为证，不宣称已完成跨引擎参数等价标定。

## 接续顺序与门槛

1. 完成当前post-authority压弯修复对照的原地面验收，保存所有失败项。
2. 显式接入Isaac材质、读取轮胎和地面绑定、combine及摩擦/恢复系数；必要的无策略接触检查不能替代行为。
3. 冻结同一候选，比较原地面、新地胶、磨损地胶在零速/停止、正负低速、慢转、1–1.5压弯关键点；与已知tracking/bank缺口分开归因。已知危险方向不直接拿实机试。
4. 地胶severity按0→.1→.25→.5→.75→1逐级覆盖，失败插小档；每档保留原地面rehearsal和retention。不是按迭代数自动晋级，也不把摩擦课程当D课程。
5. 独立记录车体速度/yaw、轮接触点滑移、左右载荷及失载持续时间、机身/腿擦地、正确倾向、起停与切换。不能用轮速代替车体速度或仅以无倾倒通过。
6. 新部署版本仍须小MLP蒸馏后独立MuJoCo多seed/动态验收及真实地胶实测。教师通过不能自动认证学生，静态MJCF通过也不能认证sim2sim。

全部工作保持25D/6D、原vx+yaw；不新增vy/导航。实机日志尚缺，当前不能承诺“彻底适应”或给高成功率数字。
