# 赛场扰动鲁棒性要求

2026-09-30 用户明确要求，纳入最终联合最高 DR 与部署验收。本文为需求和待实现契约，不是训练完成证明。

## 弹丸攻击

用户给出作用力约 40–400 N；用户进一步确认作用点在装甲板、方向随机、持续时间很短（类比乒乓球弹墙）；具体持续时间、冲量及装甲板几何尚未确定，不能仅凭峰值定义抗冲击能力。训练命中点应限制在装甲板有效表面，入射方向随机但满足该面可达的入射半空间；需覆盖装甲位置和高度、方向、脉冲波形、单发与连续脉冲，以及与操作者命令切换的相位关系。使用物理外力和作用点产生的力矩，记录实际 F(t)、积分冲量及力矩；不能以瞬时 root 速度重置冒充弹丸模型。短于仿真步长的作用按等效冲量处理并做步长敏感性验证，不将400 N持续多个控制周期默认称真实弹击。

## 云台与底盘耦合

覆盖云台相对底盘固定、世界系瞄准保持、主动转向/加减速三类状态。静态质量/COM/惯量DR不能替代云台电机对底盘的反作用力矩。优先依据云台质量、几何、转轴惯量、角度及速度/加速度边界构造耦合等效模型；需回读正定惯量与实际加载力矩，避免将已包含在整车USD中的惯量重复计入。世界系锁定不等于把云台惯量简单设为零。当前closed-loop USD拓扑保持；先可采用明确标注近似的等效扰动力矩，之后验证近似覆盖边界。

在双向小陀螺、转弯、启停时联合验收，不仅测静止站立。保持25-D部署观测，未部署可测的云台状态不偷偷加入actor输入；若确需观测变更，应单独同步训练、导出与controller契约。

## 气弹簧误差

## 验收与缺口

现有代码有root惯量缩放、旧径向气弹簧幅值DR和速度push入口；旧径向幅值随机化不会自动作用到新等效力矩模型。v349已接入等效力矩共同/左右独立偏差：名义值仍限制在10.775 N·m以内，reset采样值可覆盖工程先验±20%（8.62–12.93 N·m）。共同±10%与独立±10%采用加法组合，默认关闭；512子步原生施力和64组MuJoCo非对称广义力对照已通过，但完整分布行为与最高DR策略验收未通过。弹击冲量、云台动态反力矩、气弹簧完整误差模型尚未覆盖，不能用DR strength=1或nominal八点验收替代完整赛场验收。

先分项确定物理合理范围和失效边界，再联合渐进DR；最终在3Nm轮端持续限制、统一腿PD和同一完整策略下多seed验收：命令跟踪、跌倒率、恢复时间、载荷、侧滑、关节/执行器峰值、倒地恢复及交还。记录实际抽样与施加量，Isaac与MuJoCo复现同一扰动契约。未知持续时间与云台参数保留为待辨识项，不捏造最高DR证书。
