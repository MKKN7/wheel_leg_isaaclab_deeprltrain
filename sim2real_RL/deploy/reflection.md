## 4. 已找到的策略端事实：不能全推给硬件

### 4.1 v8 的“31项通过”并不代表向内压弯正确

[formal_acceptance_report.json](../../artifacts/h723_distill_v8/formal_acceptance_report.json) 记录同契约 Isaac 每点至少32回合、31/31教师技能保留；同时明确 `promoted=false`。更关键的是 formal_a/b 均为 `analytic_bank_required=false`，对应运行配置 `command_require_analytic_bank=false`。

当前验收源码 [evaluate_rmuc_grid.py](../../scripts/evaluate_rmuc_grid.py) 的 bank check 在未要求 analytic bank 时直接放行；[bank_geometry.py](../../source/agent_tasks/agent_tasks/direct/rmuc_wheel_leg/bank_geometry.py) 明确以“向航向左侧倾”为正，并用 `atan2(vx*yaw, 9.81)` 作准静态参考。原始报告如下：

|vx / yaw|平均有符号倾角|bank平均绝对误差|原报告|
|---|---:|---:|---|
|1.0 / +0.8|−5.044°|9.706°|passed=true，bank check=true|
|1.0 / +1.4|−7.037°|15.159°|passed=true，bank check=true|
|1.0 / −0.8|+1.547°|6.209°|passed=true，bank check=true|
|1.0 / −1.4|+4.874°|12.996°|passed=true，bank check=true|

这说明 **v8 在仿真中就有平均向弯外倾的行为**，不是必须假设实机接线错误才能解释。它不证明现场每一帧的原因，但足以否定“符号一定错、策略没有责任”。原始数值见 [formal_a](../../artifacts/h723_distill_v8/formal_a/evaluation.json)、[formal_b](../../artifacts/h723_distill_v8/formal_b/evaluation.json)。

后续应将 tracking、存活、正确倾向、双轮载荷/支撑余量分开验收；转弯瞬态允许合理反向预动作，不能要求每帧都符合准静态倾角。`atan(v*yaw/g)`也不是多接触轮腿机构所有姿态的唯一精确平衡角，应配实际加速度、COM、接触力判断。不能简单强开一个惩罚就宣布修好。

### 4.3 DR有启用，但远非“全部鲁棒性已覆盖”

正式报告为 DR strength=.1。最终采样读回（formal_a）为 Dfb约[.049003,.050976]、机械b约[.001901,.002300]、C约[.000954,.001399]；不是配置最大范围 [.04,.06]/[.001,.005]/[.0005,.005] 全部暴露。

传感器配置已启用；当时 delay_min=max=1，观测延迟概率.05、动作通信延迟概率.02，报告最大已暴露1周期。不能写成已覆盖每次1–3周期、实机任意推理抖动或长时间丢包。质量及独立惯量形状倍率读回约±2%，不是±20%；leg DR在该验收读回为false。

腿/轮 armature、响应和质量须按该版本实际读回核对，不能仅因文本提出就认定“没建模”。同样，资产质量有数值不代表带电池、云台、线缆的实机COM已对齐。

### 4.4 蒸馏还应保留反馈特性和恢复边界

v8 导出报告的PC数值对拍误差约1.52e−6，且31项Isaac技能保留，故不能笼统断言“小网络推理错了/容量必然不够”。但这不覆盖板端输入构造、CubeAI数值、未采到的切换/失稳边界和跨引擎闭环。

v8 augmentation_report明确548,864条是**局部合成扰动重标注**，不是额外真实闭环rollout，更不是最高DR覆盖。后续重点应是学生自主rollout偏离区、起停/切换、零速附近、真实传感器误差附近采样，再由经过该工况验证的冻结教师标注；不能用失败教师无条件纠正学生。训练/验证按轨迹和seed分开，避免相邻帧泄漏。

## 5. 轮阻尼补偿：该做，但要按v8实际契约做

v8 训练名义模型（两轮模型关节坐标；前进轮速为负）为：

```text
tau_motor_train = clip(-5.5*clip(a,-1,1) - 0.05*dq_joint, -5.5, 5.5)
tau_wheel_train = tau_motor_train - 0.002*dq_joint - 0.001*tanh(dq_joint/0.1)
```

既有部署参考的近似补偿路线为：

```text
tau_motor_real = clip(-5.5*clip(a,-1,1) - D_comp*dq_joint, -5.5, 5.5)
D_comp = 0.052  # v8交付参考值；必须显式填入，不是宏自动启用
```

若采用前进为正的轮坐标，统一换成 `omega_forward=-dq_joint`、`tau_forward=-tau_motor_joint` 后才可写 `clip(5.5*a-D_comp*omega_forward,±5.5)`。补偿使用观测同源、同符号的**未缩放输出轴rad/s轮速**；不能直接拿 `.05*dq` 的obs15/18作omega，也不能拿转子RPM直接代入。

当前缺少补偿意味着缺少约.05量级主动速度反馈，明显偏离v8训练闭环，优先级高。补偿在正确定义下是耗散项，但：

1. 不是单独给实机“加一个被动D”；它占电磁电流预算，必须在±5.5内部，物理b/C不能重复写成部署电流。
2. `.052 + b_real` 不等于 `.05 + .002` 的精确实现。若b_real在.001–.005，实机非饱和总斜率约.053–.057，训练该档约.0509–.0533；**当前窄DR不保证覆盖上端**。饱和区内外限幅位置还有差异。对拍和补偿A/B必须记录D_comp，不能笼统称“DR已兜住”。
3. D_comp=.05更直接对应训练主动通道，.052属于已有近似补偿选择；本次不擅自替换交付参数，也不把任何一个未测值宣布为最终值。后续用确认的机械先验/读回决定同契约小幅对照。
4. omega=0时阻尼力矩为0，它不能抵消静态偏置、提供位置保持或修正错误速度估计。不能保证补上D后不溜车、不顿挫。
5. 1ms轮执行与2ms训练不自动等价；必须包含相同滤波、保持和反馈采样。高采样频率不弥补错误的信号延迟。
6. 3Nm是持续热/负载参考，不可把瞬态峰值改成3Nm。校核Iq、实际电流上限、温度、反电动势/电压饱和；不能只检查浮点力矩变量。

`rmuc_low_level.c` 已有补偿单施加点，但初始化允许D=0，且没有替集成方自动配置.052。存在这个文件不能证明板上启用了补偿。旧控制器不同电流系数/限流代码也不能未经检查移植。实机缺项应先恢复契约，再判断余下需要RL适应的残差，不能让DR替代正确映射。

|参考控制器已保证线程安全|没有。当前setter用memcpy，step读取共享action；按串行调用可用，RTOS并发集成须外部同步。其8ms deadline返回零输出，实际固件若超时/忽略状态可能断力矩；必须记录返回码与真实墙钟，不能说已找到板端bug|
|切换一律0.5s q_target斜坡|平滑接管有价值，但不是通用常数；从当前q到有效策略目标、history/估计初始化都要一致。对平衡车过慢会丢失纠偏；持续给策略action低通会增加相位滞后。接管逻辑须进入仿真验收|
|落地冻结常数action几秒，靠PD硬撑即可分流|**不采用。** 固定腿PD不能替代轮腿平衡闭环，常数轮力矩本身会失稳，不能据此定位推理。用架空/受约束执行器台架或离线重放测试时序|
|推理615微秒且周期8ms→必然阻塞1ms环|推理耗时本身不能证明抢占、CAN或ISR丢拍；需测真实deadline、WCET、优先级/中断屏蔽、CAN间隔、每轮最新action年龄。更高频也不必然良性|
|缺D使系统从一阶变积分器，所以顿挫已定案|孤立轮模型仅是直觉；落地轮腿是耦合非线性闭环。不能忽略惯量、接触、传感器估计、限流和时延，更不能据此证明因果|
|垫上顺、瓷砖顿=打滑实锤；以后只测瓷砖|只能增强接触相关假设；同时控制线缆、命令、姿态、电池等并测轮面速度与车体速度。保留硬地/垫及接缝测试，赛场摩擦需依据，不把tile外观当认证|
|换电池减轻→高电压让电机必然更猛|电流闭环下不简单成立。可能是电压掉落、反电动势余量、驱动欠压/保护、接插件，或换电池同时改变质量/COM。需电压和Iq/故障码|
|弹簧差8.35Nm确定，q0统一减8°修正|10.775−2.424375=8.350625是两套等效模型参数差，**不是实机每姿态实测关节力矩差**。弹簧力—行程、安装点、Jacobian及两侧符号决定实际量；q0是传感器/动作基准，不能无证据更改掩盖动力差|
|立即把弹簧DR撒满[2.4,10.775]|跨度大且等效律待对应，可能同时破坏已学技能。保持真实硬件依据，逐级迁移并测retention，不凭照片套V14弹簧，也不重新启用未验证径向力|
|质量/COM差>5%就定罪|质量用kg/相对比例、COM用三轴m及参考系分别记录；没有通用5%COM判据，质量差不等于COM差。两点悬吊只是测量方法之一，不能单凭偏差锁定原因|
|零命令漂移因为没有任何静止reward|源码有stillness/action-rate项，该版本运行配置command_stillness_weight=.05；不能称完全没约束。更准确问题是覆盖、权重和验收不足。没有位置误差输入的25D不支持任意世界目标位置闭环，先强化零速/零yaw和停止后漂移指标|
|教师Isaac过、教师MuJoCo不过→一定MJCF几何错|只能定位到跨仿真链；还可能是初始化、obs、消费器、反馈采样、接触/solver或时序不同。教师/学生×Isaac/MuJoCo四格同契约对照才有区分力|

## 7. 策略端改进顺序：先消除已知缺口，再扩能力

以下是待执行修复路线，不是已经完成或已启用。保持25D/6D、原vx+yaw command，不增加vy/导航或未训练速度/pitch/yaw外环。

1. **冻结v8问题基线。** 保留ONNX/固件版本、原视频及失败条件；另开候选。按本页五类症状制定回归，不能以教师后来学会或新模型均分高替代v8归因。
2. **优先核对闭环接入与接管。** 实机缺D先补同契约实施；同时检查obs时间一致性、action整帧提交、history、失效状态码和切换初始化。先离线/支撑验证方向、电流，再做限域闭环；不以训练克服接线、数组竞争或未处理的控制错误。
3. **修验收盲区。** 固定记录实际向内倾向、载荷、支撑余量和擦地，不让bank绕过的stage pass充当“压弯通过”。零命令/起停/反向/切换设独立必过项；事故前瞬态不能被稳态均值或允许少量失败的survival阈值掩盖。
4. **针对实际失败状态训练。** 零速及小速度连续采样、同幅值正负vx、慢yaw、切换附近初态；保留旧技能rehearsal。对较小倾角/角速度就开始偏离的状态给予平滑恢复奖励，联合speed/yaw、双轮支撑/高度/碰撞代价，避免只降action-rate导致“动作小但不响应”。具体权重用同预算对照决定。
5. **补部署观测分布。** 特别是obs6的真实车体速度估计：轮速平均在打滑、腿运动、转弯时不等于训练真值。用实测日志构造速度偏置/滤波延迟、IMU偏置/安装残差、编码器误差及相关噪声；纯独立白噪声不足以替代系统性估计误差。不要人为把obs槽改成另一种语义。
6. **最小真实动力残差课程。** 在正确限幅内反馈律上采样Dfb、机械b/C和左右差异；响应/延迟从已过档逐级加。质量/COM/云台、力矩增益、电压导致的可达力矩、弹簧工作点按证据加入，单独做消融，避免一次改全部导致无法归因。正常实现必须正确，极端数据竞争/NaN不交给RL兜底。
7. **保持小MLP结构，改采样和闭环蒸馏。** 25→128→128→6继续作为部署规格；优先增加学生偏离轨迹与失败邻域数据，必要时对相邻状态反馈响应作蒸馏约束。教师本身有反向压弯时，先修教师；不能要求学生忠实复制后又期望它自动正确。
8. **学生独立部署门槛。** ≥教师90%只是相对门槛，还须关键条件无观察倾倒、正确压弯/无擦地、零速和切换通过。逐档验Isaac学生与同契约MuJoCo学生，再做CubeAI相同输入对拍/板端时序、受控实测。Demo只展示成功片段，不能替代完整失败清单和统计。

原训练主线“≤1.5目标域稳定后再继续弹簧迁移”未在本次自动改动；但“稳定”必须包含这次暴露的安全与压弯缺口，不能仅复用旧宽松通过计数。当前暂停于复盘任务，没有依据本页猜测启动大范围DR长训。

## 8. 下一次日志怎样一次分清问题

每次启动保存模型/固件hash、D_comp左右值、电流映射和限值、腿PD/scale/零位、传感器变换、实际周期、地面/电池/云台配置。同步记录故障前至少2s及故障后短窗口，视频用可见事件/时间标记对齐；日志本身不可阻塞控制环。

最小实验顺序：

1. 离线同输入对拍和逐轴支撑检查；同时核对action/obs一致快照、切换历史与实际状态码。架空不认证平衡。
2. 正确实现并核对补偿，以相同低风险命令/初态对照，记录补偿值和真实电流。若已有其他阻尼反馈先消除重复；不在地面用常数action冻结法。
3. 同初态、同幅值正负低速、零速停止、慢转及进入/退出；硬地与垫分组重复，去除拖线/扶持混杂并单独记录垫边。先复现排序第1项，出现突摆/擦地即按实机保护流程结束该试次。
4. 将实际失败命令与状态映射到同一v8/教师、同物理契约的四格对照；优先用已有报告，只有缺证据的格子才新增仿真实验。**先找误差从哪一层开始，再决定修代码、修模型或续训。**
